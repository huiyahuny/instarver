MOMENTA · 관리자와 방문자가 한 화면에서 입장하는 버전
===================================================

1. 파일 구성
   index.html    : 홈페이지 첫 화면 (관리자 별도 페이지 없음)
   styles.css    : 화면 디자인
   app.js        : 게시물, 댓글, 좋아요, 권한 처리
   config.js     : 운영자 아이디와 인증값을 직접 입력
   assets/       : 시연용 그림

2. 관리자 아이디 설정
   config.js 파일에서 이 두 줄을 바꾸세요.

   ADMIN_ID: '[이곳에 관리자 아이디를 입력하시오]',
   ADMIN_CODE: '[이곳에 관리자 인증 값을 입력하시오]',

   예시 (직접 사용할 비밀번호는 별도로 정하세요):
   ADMIN_ID: 'myowner',
   ADMIN_CODE: 'example-code-5678',

   따옴표와 줄 끝 쉼표(,)는 그대로 둡니다.
   DEMO_POSTS: true는 샘플 게시물 3개 표시, false는 빈 피드를 표시합니다.

3. 입장 방법
   - 사이트 index.html에서 모두 같은 '이름으로 입장' 화면을 사용합니다.
   - 관리자는 ADMIN_ID로 정한 아이디 + ADMIN_CODE로 정한 인증값 입력.
   - 방문자는 본인 이름 + 본인이 정한 PIN(4자 이상)을 입력.
   - 관리자 전용 '게시물 만들기'가 왼쪽 메뉴/모바일 하단에 나타납니다.
   - 방문자에게는 게시물 만들기, 삭제, 수정, 프로필 편집, 팔로우,
     스토리 올리기 기능이 나타나지 않습니다.
   - 방문자가 할 수 있는 상호작용은 댓글과 좋아요입니다.

4. 게시물 작성 방법 (관리자)
   사진 선택 -> 글 작성 -> [게시물 공유하기] 클릭.
   게시물 오른쪽 위 점 세 개 메뉴로 사진/글 수정 및 삭제가 가능합니다.
   스토리도 관리자만 올릴 수 있습니다.

5. 테스트 방법
   PC에서 index.html 더블클릭 또는 GitHub Pages 사이트를 엽니다.
   관리자 로그인 -> 글과 사진 올리기 -> 로그아웃 -> 방문자 이름으로 로그인
   -> '게시물 만들기' 메뉴가 사라지는지 확인 -> 좋아요/댓글 테스트.

6. 매우 중요한 제한 (정식 서비스가 아닙니다)
   이 사이트는 브라우저 내부 localStorage에 저장하는 시제품입니다.
   A라는 사람이 글을 올려도 B의 컴퓨터/브라우저에는 공유되지 않습니다.
   GitHub Pages에 업로드만 해서는 실제 공동 게시물/댓글 서비스가 되지 않습니다.
   여러 사람이 함께 글을 보고 댓글을 달려면 서버/공용 DB가 필요합니다.
   관리자 아이디와 인증값이 공개 config.js에 있으므로 누구나 확인할 수 있습니다.
   화면의 역할 구분은 실제 계정 보안이 아닙니다.
   실서비스에서는 서버가 관리자 권한을 검증해야 합니다.
   실제로 사용하는 다른 서비스의 비밀번호를 여기에 사용하지 마세요.

7. GitHub Pages 공개
   새 Public 저장소에 index.html, app.js, config.js, styles.css, assets/
   내용을 업로드하고 Settings > Pages > Deploy from a branch,
   main, /(root)로 설정합니다.
   기존 저장소에 이전 버전의 admin.html이 남아 있다면 직접 삭제해야 합니다.

MOMENTA는 인스타그램 공식 서비스가 아닌 독립적인 UI 시제품입니다.
